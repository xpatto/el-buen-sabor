# Reglas permanentes

- Consultar `docs/ALCANCE.md` antes de cualquier cambio.
- No agregar funcionalidades no autorizadas.
- Mantener el proyecto sencillo, modular y por capas.
- Usar nombres descriptivos y código entendible.
- Mantener controladores, servicios y repositorios separados cuando se implementen.
- No duplicar lógica ni introducir dependencias innecesarias.
- No almacenar secretos, contraseñas ni bases de datos de producción en Git.
- Validar entradas y preservar la seguridad de la API administrativa.
- Crear o actualizar pruebas por cada funcionalidad.
- Ejecutar pruebas y comunicar sus resultados reales antes de realizar commits.
- No declarar exitosas pruebas que no se hayan ejecutado.
- Mantener README y documentación actualizados.
- No hacer push ni cambios remotos sin autorización.
